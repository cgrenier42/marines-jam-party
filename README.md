# Marine's Jam Party 🦊🐸🐷

Un petit jeu de puzzle pour Android : fais sortir les parents du plateau dans le bon ordre pour qu'ils retrouvent leurs petits, sans encombrer les places d'attente !

Le jeu fonctionne entièrement hors ligne et ta progression est sauvegardée sur ton téléphone.

## 📥 Installer le jeu

1. Sur ton téléphone Android, télécharge la dernière version :
   **[⬇️ MarinesJamParty.apk](https://github.com/cgrenier42/marines-jam-party/releases/latest/download/MarinesJamParty.apk)**
2. Ouvre le fichier téléchargé (depuis la notification ou l'appli *Fichiers*).
3. Si Android affiche « Pour des raisons de sécurité, votre téléphone n'est pas autorisé à installer des applis inconnues », appuie sur **Paramètres**, active **Autoriser cette source**, puis reviens en arrière.
4. Appuie sur **Installer**. C'est prêt !

Il faut Android 8 ou plus récent.

> Le jeu ne vient pas du Play Store, c'est pour ça qu'Android pose la question. Il ne demande aucun accès à tes photos, contacts ou données : il se connecte seulement à cette page pour vérifier s'il existe une nouvelle version.

## 🔄 Mises à jour

Pas besoin de revenir ici : quand une nouvelle version est disponible, le jeu te le propose au lancement. Appuie sur **Mettre à jour**, puis confirme sur l'écran d'Android.

La première fois, Android te demandera d'**autoriser le jeu à installer des applis** : active l'option, puis reviens dans le jeu.

Ta progression est conservée lors des mises à jour.

## 📜 Versions

Les nouveautés de chaque version sont dans les [Releases](https://github.com/cgrenier42/marines-jam-party/releases).

## ❓ Un souci ?

- **« Application non installée »** : désinstalle l'ancienne version puis réinstalle-la (attention, cela efface la progression).
- **Pas de son** : vérifie que le téléphone n'est pas en mode silencieux et touche l'écran une fois dans le jeu.
- Pour toute autre question, écris-moi directement 🙂
